# expsite_data_media Support

## Issues and bug reports

Report bugs and feature requests on the issue tracker:

- https://github.com/se7enxweb/expsite_data_media/issues

Please include the installer output, the database type and the `VarDir` setting in use. Do not attach database dumps containing personal data.

## Security issues

Do not open public issues for security problems. Report them privately to info@se7enx.com.
